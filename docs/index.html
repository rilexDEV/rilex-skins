Install in 3 stepsالتثبيت بـ 3 خطوات

No files to unzip. The Horizon launcher takes it straight from GitHub.

ما في ملفات تفكّها. الـ launcher بياخده من GitHub مباشرة.

1

Add from GitHub

زيدو من GitHub

Launcher → Mods → Add from GitHub, paste:

بالـ launcher: Mods ← Add from GitHub، والصق:

https://github.com/rilexDEV/rilex-skins
2

Build once

ابنِ مرة وحدة

Press Build in the native build row. First build: 20–30 min. After that: minutes.

اكبس Build. أول مرة 20 لـ 30 دقيقة، بعدين دقايق.

3

Claim your name

احجز اسمك

In game: /rilexskin register and write down your recovery code.

باللعبة: /rilexskin register واكتب الـ recovery code على ورقة.

Commandsالأوامر

/rilexskin register NAMEClaim your name, once. Shows your recovery code.احجز اسمك مرة وحدة. بيطلعلك الـ recovery code.
/rilexskin set PATH slimUpload a 64×64 PNG skin — classic or slim arms.ارفع سكن PNG قياس 64×64، classic أو slim.
/rilexskin backupSave your key to a file. Keep it on a USB stick or phone.احفظ مفتاحك بملف، وخلّيه على فلاشة أو تلفون.
/rilexskin restore FILEYour name on a new computer.اسمك على كمبيوتر جديد.
/rilexskin recover NAME CODELost your key? Recovery code + admin approval.ضيّعت المفتاح؟ الـ recovery code مع موافقة الـ admin.
/rilexskin statusWhat this computer holds.شو موجود على هالكمبيوتر.

Why it's safeليش آمن

🔑

Your key = your name

مفتاحك = اسمك

Every change is signed with an Ed25519 key that never leaves your computer. Nobody can take your name or change your skin.

كل تغيير موقّع بمفتاح Ed25519 ما بيطلع من جهازك. ما حدا بيقدر ياخد اسمك أو يغيّر سكنك.

🛡️

Checked on the server

تحقّق بالسيرفر

SHA-256, size and format checks, timestamps against replays, rate limits on every request.

SHA-256، فحص الحجم والصيغة، وقت لكل طلب ضد التكرار، وحدّ لعدد الطلبات.

⚠️

Never share your key

لا تعطي مفتاحك لحدا

Support will never ask for your key file. Only the recovery code, only in the recover command.

الـ support ما رح يطلب ملف المفتاح أبداً. بس الـ recovery code، وبس بأمر الـ recover.
