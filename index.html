Your skin.
Offline. Everywhere.

سكنك.
بلا حساب. بكل مكان.

A Horizon mod that gives every offline player their own skin — protected by a key only you hold, seen by everyone who plays with RILEX SKINS.

mod لـ Horizon بيعطي كل لاعب offline سكن خاص فيه، محمي بمفتاح إلك وحدك، وبيشوفه كل حدا عنده RILEX SKINS.

Download the modنزّل الـ mod GitHub

Install in 3 stepsالتثبيت بـ 3 خطوات

1

Add from GitHub

زيدو من GitHub

In the Horizon launcher: Mods → Add from GitHub, paste:

بالـ launcher: Mods ← Add from GitHub، والصق:

https://github.com/rilexDEV/rilex-skins
2

Build once

ابنِ مرة وحدة

Press Build on the native build row. The first build takes 20–30 minutes; later ones are quick.

اكبس Build. أول build بياخد 20 لـ 30 دقيقة، بعدين بيصير سريع.

3

Claim your name

احجز اسمك

In game, type the commands below. Write down your recovery code.

باللعبة اكتب الأوامر تحت، واكتب الـ recovery code على ورقة.

Commandsالأوامر

/rilexskin register NAMEClaim your name (once). Shows your recovery code.احجز اسمك (مرة وحدة). بيطلعلك الـ recovery code.
/rilexskin set PATH slimUpload a 64×64 PNG skin (classic or slim arms).ارفع سكن PNG قياس 64×64 (classic أو slim).
/rilexskin backupSave your key to a file. Keep it on a USB stick or phone.احفظ مفتاحك بملف، وخلّيه على فلاشة أو تلفون.
/rilexskin restore FILEUse your name on a new computer.استعمل اسمك على كمبيوتر جديد.
/rilexskin recover NAME CODELost your key? Your recovery code + admin approval brings it back.ضيّعت المفتاح؟ الـ recovery code مع موافقة الـ admin بيرجّعلك اسمك.
/rilexskin statusWhat this computer holds.شو موجود على هالكمبيوتر.

Why it's safeليش آمن

Your key, your name

مفتاحك = اسمك

Every change is signed with an Ed25519 key that never leaves your computer. Nobody can take your name or change your skin.

كل تغيير موقّع بمفتاح Ed25519 ما بيطلع من جهازك. ما حدا بيقدر ياخد اسمك أو يغيّر سكنك.

Checked on the server

تحقّق بالسيرفر

SHA-256, size and format checks, timestamps against replays, and rate limits on every request.

SHA-256، فحص الحجم والصيغة، وقت لكل طلب ضد التكرار، وحدّ لعدد الطلبات.

Never share your key

لا تعطي مفتاحك لحدا

Support will never ask for your key file. Only the recovery code is used, and only in the recover command.

الـ support ما رح يطلب ملف المفتاح أبداً. بس الـ recovery code، وبس بأمر الـ recover.
